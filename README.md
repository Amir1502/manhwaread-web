## 🌟 Ключевые возможности

### 🎛 1. Каталог и фильтры в стиле MangaLib
- **Выпадающее меню сортировки**: 9 критериев сортировки с выбором направления (*По убыванию* / *По возрастанию*) и фирменными радио-метками:
  - *По популярности*, *По рейтингу*, *По просмотрам*, *Количеству глав*, *Дате релиза*, *Дате обновления*, *Дате добавления*, *По названию (A-Z)*, *По названию (А-Я)*.
- **Боковая панель фильтрации** (адаптивный десктопный сайдбар и мобильная шторка):
  - **Жанры и теги**: мульти-выбор популярных категорий (*Сёнен, Романтика, Боевик, Исекай, Система, Реинкарнация* и др.).
  - **Числовые диапазоны**: гибкая фильтрация *«От — До»* для количества глав, года выхода и рейтинга.
  - **Возрастной рейтинг**: `6+`, `12+`, `16+`, `18+`.
  - **Тип и формат**: Манхва, Маньхуа, Манга, Руманга, Вебтун, В цвете, 4-кома, Сборник, Сингл.
  - **Статус тайтла**: Онгоинг, Завершён, Приостановлен, Выпуск прекращён.
  - **Мои списки**: мгновенная выборка из закладок пользователя (*Читаю, В планах, Любимые, Прочитано, Брошено*).
- **Зелёные бейджи рейтинга**: отображение точной оценки на обложке тайтла (`9.8`, `9.5`).

### 🧹 2. Умная дедупликация и очистка каталога
- **Без дубликатов**: канонический алгоритм нормализации названий (`normalizeTitleKey`) объединяет одинаковые тайтлы из разных источников в одну лучшую карточку.
- **Исключение тайтлов без глав**: лицензированные заглушки и анонсы с `0` глав автоматически отсеиваются в пользу источников с доступными главами.

### 💬 3. Комментарии под главами и страницами
- Комментирование как целой главы, так и **отдельной страницы читалки** (как на MangaLib).
- Древовидные ответы на комментарии (Replies).
- Лайки и дизлайки с подсчётом рейтинга каждого комментария.

### 👤 4. Система аккаунтов и уровней
- Быстрая регистрация без обязательной электронной почты (только логин и пароль).
- **Система уровней и рангов MangaLib**: опыт (XP) за чтение, ранги от *Новичка* до *Мудреца*.
- Личный профиль с возможностью загрузки аватара и описания.
- Безопасное хранение паролей (PBKDF2 + соль) и надёжное сохранение сессий.

### 📖 5. Удобная читалка
- Режимы чтения: **вебтун** (непрерывная вертикальная лента) и **постраничный**.
- Настраиваемая ширина ленты, тап-зоны для мобильных устройств, клавиатурные стрелки для ПК.
- Оглавление с поиском глав, автоматическое запоминание последней страницы и отметка прочитанного.
- Умная предзагрузка следующих страниц для плавного чтения без задержек.

### ⚡ 6. Векторный AI-оверлей
- Интерактивный демонстрационный режим для наложения переведённого текста поверх оригинальных сканов манхвы.

### ⏱ 7. Встроенный фоновый Keep-Alive пингер
- Автоматический пингер, предотвращающий засыпание веб-сервиса на бесплатных тарифах хостинга (например, Render).

## 📚 Поддерживаемые источники

| Источник | Тип интеграции | Особенности |
|---|---|---|
| **MangaLib** (`mangalib.me`) | Официальный API | Рейтинг, метаданные, просмотры, сортировка |
| **ReManga** (`remanga.org`) | API v2 | Высокое качество глав, фильтрация платного контента |
| **Com-X** (`com-x.life`) | Smart Fast Parser | Полная база глав и манхв с автоматическим обходом DDoS-Guard |
| **MangaMir** (`mangamir.com`) | HTML Parser | Резервный источник глав с быстрой отдачей |
| **MangaDex** (`mangadex.org`) | API v5 | Глобальная база, приоритет русскоязычных переводов |
| **Manga18fx** *(18+)* | HTML Parser | Контент для взрослых (включается тумблером 18+) |

> 🔒 **Защита изображений**: Все страницы и обложки передаются через защищённый внутренний прокси `/api/proxy-image` с белым списком разрешённых CDN-хостов и автоматической подстановкой заголовков `Referer`.
