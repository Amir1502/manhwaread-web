# ManhwaRead Web — Полноценная Web-читалка манхвы

Современная веб-читалка манхвы и манги, портированная из репозитория [Amir1502/manhwaread](https://github.com/Amir1502/manhwaread), оптимизированная для деплоя на **Vercel** и привязки к домену **`my.to`** (FreeDNS).

---

## ⚡ Возможности

1. **Источники** (единый каталог, поиск, популярное/обновления, главы и страницы):

   | Источник | Тип | Примечание |
   |---|---|---|
   | MangaLib (mangalib.me) | API `api.cdnlibs.org` | лицензированные тайтлы без глав |
   | ReManga (remanga.org) | API v2 | платные главы скрыты; API геоблокирует часть зарубежных IP |
   | MangaMir (mangamir.com) | HTML-парсер | строки «Прогноз» отбрасываются |
   | MangaDex | API v5 | рейтинг из `/statistics`, приоритет RU-переводов |
   | Manga18fx (18+) | HTML-парсер | скрыт, пока не включён переключатель 18+ |

   Картинки идут через `/api/proxy-image` с allowlist хостов каждого источника и нужным `Referer`.
2. **Читалка**: вебтун и постраничный режим, тап-зоны, клавиатура, предзагрузка, оглавление, ширина ленты, восстановление прогресса, отметка прочитанного.
3. **Векторный AI-оверлей (`OverlaySpec`)** — демо-тайтл «Демо: векторный AI-оверлей».
4. **Библиотека**: статусы («Читаю», «В планах», «Прочитано», «Брошено») и история с обложками — в `localStorage`.
