# ManhwaRead Web — Полноценная Web-читалка манхвы

Современная веб-читалка манхвы и манги, портированная из репозитория [Amir1502/manhwaread](https://github.com/Amir1502/manhwaread), оптимизированная для деплоя на **Vercel** и привязки к домену **`my.to`** (FreeDNS).

---

## ⚡ Ключевые возможности

1. **Режимы чтения**:
   - **Вебтун (Webtoon)**: Бесконечная вертикальная плавная лента для манхвы с адаптивной шириной (750px / 950px / 1200px / 100%).
   - **Постраничный режим**: Классическое чтение манги (клики, клавиши `←` / `→`).
2. **Фирменный векторный AI-оверлей (`OverlaySpec`)**:
   - Текст перевода рендерится как независимый векторный слой прямо поверх бабблов (без запекания в растр и потери резкости).
   - Клик по бабблу мгновенно переключает язык между оригиналом и русским переводом.
3. **Источники и Каталог**:
   - Интеграция с официальным **MangaDex API v5** (поиск, популярное, главы на русском и английском).
   - Встроенный каталог топовых тайтлов (*Solo Leveling, Omniscient Reader, TBATE, Tower of God*).
4. **Моя библиотека и История**:
   - Сохранение прогресса (глава, страница) и списков («Читаю», «В планах», «Прочитано», «Брошено») в `localStorage`.
5. **Дизайн-система**:
   - Глубокая OLED-темная тема (`#090A0F`), акцентный Mangalib-оранжевый (`#FF6740`), неоновый AI-фиолетовый (`#8B5CF6`), плавающие HUD-панели и стеклянные эффекты.

## 🚀 Деплой на Vercel за 1 минуту

### Вариант 1: Через Vercel CLI
```bash
cd manhwaread-web
npx vercel
# Нажмите Enter на все стандартные вопросы
```

### Вариант 2: Через GitHub
1. Создайте репозиторий на GitHub и запушьте папку `manhwaread-web`.
2. Зайдите на [vercel.com](https://vercel.com) → **Add New Project** → выберите ваш репозиторий.
3. Framework Preset автоматически определится как **Next.js**. Нажмите **Deploy**.

## 🌐 Привязка бесплатного домена `*.my.to` (FreeDNS) к Vercel

1. **В панели Vercel**:
   - Перейдите в ваш проект → **Settings** → **Domains**.
   - Введите желаемый адрес: например, `manhwa.my.to` (или `read.my.to`) и нажмите **Add**.
   - Vercel покажет DNS-инструкцию: для поддомена нужен **CNAME** на `cname.vercel-dns.com` (или A-запись `76.76.21.21`).

2. **В панели FreeDNS (afraid.org)**:
   - Зайдите в раздел **Subdomains** → **Add**.
   - **Type**: выберите `CNAME` (или `A`).
   - **Subdomain**: введите ваше имя (например `manhwa`).
   - **Domain**: выберите `my.to`.
   - **Destination**: введите `cname.vercel-dns.com` (или `76.76.21.21` при типе A).
   - Сохраните.

Через 2–5 минут статус домена в Vercel станет зеленым, и Vercel **автоматически выпустит бесплатный SSL-сертификат Let's Encrypt**!
